# 📱 RF 工具箱

一个基于浏览器的射频工程分析工具，支持 **S参数文件可视化** 和 **常用 RF 计算**，无需安装、无需服务器，部署到 GitHub Pages 后手机/电脑均可直接使用。

🔗 **在线演示**：`https://cb17943.github.io/rf-toolkit/`

---

## ✨ 功能概览

### 计算器
| 功能 | 说明 |
|------|------|
| **keff² 计算** | 输入 fs、fp（MHz），按公式 `k²eff = 2.4674 × fs/fp × (fp−fs)/fp × 100` 输出机电耦合系数 |
| **dB ↔ Ohm 换算** | 支持双向换算：`dB = 20×log₁₀(Ohm)` / `Ohm = 10^(dB/20)` |

### S参数分析
| 功能 | 说明 |
|------|------|
| **文件导入** | 支持 `.s1p` / `.s2p` 批量导入，自动识别 RI/MA/DB 格式和 Hz/kHz/MHz/GHz 单位 |
| **\|Z\| 阻抗幅度图** | dBΩ 线性 / Ω 对数双模式切换 |
| **Bode Quality Factor** | 基于群延迟计算 BodeQ |
| **Smith Chart (S₁₁)** | 等电阻圆 + 等电抗圆背景，显示 S₁₁ 轨迹 |
| **\|S₂₁\| 图** | s2p 文件插损/增益幅度图 |
| **Marker 系统** | 右键自动找最近数据点添加 Marker；支持精确搜索添加、列表管理、批量清除 |
| **框选放大** | 桌面端左键拖拽框选放大，一键重置视图 |
| **保存图像** | 导出当前图表为 PNG |

## 🚀 快速部署


直接双击 `index.html`，用浏览器打开即可。Chrome/Safari/Edge 均可。

---

## 📋 支持的 Touchstone 格式

| 参数 | 支持值 |
|------|--------|
| 文件类型 | `.s1p` (1-port), `.s2p` (2-port) |
| 格式 | RI (实部+虚部)、MA (幅度+相位°)、DB (dB+相位°) |
| 频率单位 | Hz、kHz、MHz、GHz |
| 参考阻抗 | 自动读取 `#` 行中的 `R` 值（默认 50Ω） |

> ⚠️ 同一次导入请选择同一类型文件（全部 `.s1p` 或全部 `.s2p`），不支持混导。
